# 🎬 VYBE – Premium OTT Streaming App UI/UX Design

## 1. Project Description

VYBE is a modern premium OTT (Over-The-Top) streaming mobile application UI/UX design created using Figma. It provides a cinematic and user-friendly interface for discovering, browsing, and watching movies and web series.
The application uses a premium dark theme with black, purple, and red accents. It focuses on intuitive navigation, personalised content discovery, and an improved user experience.

## 2. Aim

To design a modern, attractive, and user-friendly OTT streaming mobile application interface that allows users to explore movies, watch web series, manage their watchlist, and enjoy a seamless digital entertainment experience.

## 3. Objectives

- To create an attractive and consistent mobile application interface.
- To provide easy navigation between different application screens.
- To improve movie and series discovery through search and categories.
- To design personalised content recommendations.
- To provide a simple watchlist management interface.
- To improve usability through readable typography and accessible controls.
- To create a consistent design system using reusable UI components.

## 4. Algorithm

**Step 1:** Start the VYBE application.

**Step 2:** Display the splash screen with the VYBE logo and welcome message.

**Step 3:** Allow the user to sign in or create an account.

**Step 4:** Display the profile selection screen.

**Step 5:** Navigate the user to the home screen.

**Step 6:** Display featured movies, recommended content, and Continue Watching.

**Step 7:** Allow the user to search for movies and web series or browse by genre and mood.

**Step 8:** When the user selects a title, display its details, description, and available episodes.

**Step 9:** Allow the user to add the selected title to My List or choose the Play option.

**Step 10:** Display the video player interface with playback controls and progress indicators.

**Step 11:** Allow the user to manage profiles, subscription preferences, language, subtitles, and account settings.

**Step 12:** End the application session when the user signs out.

## 6. Modules

1. **Splash Module:** Displays the application logo and welcome screen.
2. **Authentication Module:** Provides sign-in and account creation interfaces.
3. **Profile Module:** Allows users to select and manage profiles.
4. **Home Module:** Displays featured content and personalised recommendations.
5. **Search Module:** Helps users find movies and web series.
6. **Movie Details Module:** Displays movie information, descriptions, and episodes.
7. **Video Player Module:** Provides playback controls and viewing progress.
8. **My List Module:** Allows users to manage saved movies and series.
9. **Settings Module:** Provides account, subscription, language, and parental control options.
